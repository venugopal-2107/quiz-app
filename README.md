# Quiz App

A Flutter quiz app with multiple-choice questions, results, and a score tracker.

## Project files
- `lib/main.dart` — Flutter app source code
- `pubspec.yaml` — Flutter package configuration
- `app-release.apk` — Android APK build, if included

## Run from a Flutter development environment
1. Install Flutter.
2. Open this project folder in a terminal.
3. Run `flutter pub get`.
4. Run `flutter run`.

Note: This is a minimal source project structure. If you want to rebuild Android APKs from source, Flutter's Android platform project files may need to be generated with `flutter create .` in a Flutter environment.
